## 二、前期需求确认（规划阶段）

在动手前通过多轮提问，明确了以下设计决策：

| 决策项 | 选定方案 | 说明 |
|--------|----------|------|
| 页面语言 | **中英双语** | 中文为主，英文辅助 |

## 三、V1 开发关键步骤

### 步骤 1：创建项目结构

在工作目录下新建 `personal-homepage/`，包含子目录与文件：

```
personal-homepage/
├── index.html          # 主页面（中英双语 + 五大板块）
├── css/style.css       # 样式（响应式 + 卡片 + 主题色变量）
├── js/main.js          # 交互（导航高亮 / 移动端菜单 / 滚动淡入）
├── assets/             # 图片资源（头像、证书图等）
├── .gitignore          # 忽略 macOS 系统文件等
└── README.md           # 本地预览 + GitHub Pages 部署说明
```

### 步骤 2：编写基础页面

- `index.html`：中英双语，含 Hero 首屏、个人简介、爱好、项目·作品、教育经历、联系方式、页脚。
- `css/style.css`：现代简洁风格，卡片式布局，`:root` 变量控制主题色，`@media` 实现响应式。
- `js/main.js`：原生 JS，实现移动端菜单开关、滚动导航高亮、滚动淡入动画、页脚年份自动更新。

### 步骤 3：本地预览验证

- 启动本地服务器：`python3 -m http.server <端口>`
- 说明：端口 8000 可能被占用，改用 8010 成功；随后验证 `index.html / css / js` 均返回 200。

> 开发建议：用本地服务器预览比直接双击 `file://` 打开更规范（避免部分功能受限）。

### 步骤 4：头像改为图片

- `index.html` 的 `.avatar` 由文字占位改为 `<img>`，引用 `./assets/avatar.png`。
- `css/style.css`：`object-fit: cover` 让图片铺满并裁成圆形；`overflow: hidden` 圆角裁剪；加载失败时显示纯色圆兜底。
- `README.md` 同步更新头像使用说明。
- 用户最终提供真实照片 `assets/avatar.png`（后续已确认正常显示）。

## 六、关键经验备忘

1. **最简可行优先**：纯静态页优于引入框架，可大幅降低落地复杂度。
2. **隐私安全**：联系方式默认占位，邮箱混淆展示（`name [AT] domain [DOT] cn`）。
3. **相对路径**：全站用 `./` 相对路径，可适配 GitHub Pages 子路径部署而不 404。
4. **本地预览规范**：用 `python3 -m http.server` 而非双击，避免 `file://` 限制。
5. **用图片时要验证**：复制图片后用 curl 检查资源可达性（200）。
6. **以事实为准**：涉及奖项名称、时间等，以证书 / 官方信息为准，及时纠正笔误。
